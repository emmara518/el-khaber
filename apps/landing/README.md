# @khabir/landing

Marketing landing page for الخبير. Next.js (static-first).

## Scripts

| Command | Purpose |
| --- | --- |
| `pnpm --filter @khabir/landing dev` | Dev server on `http://localhost:3002` |
| `pnpm --filter @khabir/landing build` | Production build |
| `pnpm --filter @khabir/landing start` | Run production build |
| `pnpm --filter @khabir/landing typecheck` | TypeScript check |
| `pnpm --filter @khabir/landing lint` | ESLint |

Final marketing copy is delivered by the Product Owner and integrated in later tasks.
