## 4. Security findings closed

- `pnpm audit --prod`: **117 → 16** advisories (6 critical / 60 high → 0
  critical / 4 high). The four remaining highs are dev/build-only Expo
  tooling with no upstream fix (`image-size` ×2, `node-forge`, `braces`);
  they are allowlisted **with owner + expiry 2026-11-20** and enforced by
  `scripts/audit-gate.mjs`. Expired entries fail CI.
- Admin role mismatch now returns **403** and missing role metadata denies.
- `finance_admin` has no privileged route (legacy `/admin/me` only).
- Refresh-token replay race closed; concurrent reuse yields one session.
- Auth throttling no longer throttles every route (the previous named
  throttler applied globally).
- Payment proof links are capped at 5 minutes.
- Weak/short JWT secrets fail startup.

## 5. Known limitations / deviations

1. **Schema drift baseline**: two PostGIS GIST indexes on `coordinates`
   cannot be expressed in Prisma 5; they are preserved in migrations and
   recorded in `apps/api/prisma/schema-drift-baseline.sql`. Any *other*
   drift fails CI.
2. **General HTTP throttle is per-instance in memory.** With N instances the
   effective request budget is N × configured. Auth throttling and login
   lockout are PostgreSQL-backed and shared. This is documented in
   `docs/security/rate-limiting.md` and startup logs.
3. **No visual UAT of the mobile offline/error states was performed on a
   device.** The states were typechecked, unit-tested, and the web export
   builds. The master task requires device screenshots; that remains open.
4. **Password reset UAT email** against a live provider was not executed
   (requires owner-provided provider credentials and approval).
5. **k6/Artillery load tests, multi-IP checks, and distributed rate-limit
   verification were not run.** No paid infrastructure was created.
6. **No production database, no Render deploy, no secret rotation, and no
   migrations were applied to khabir-dev/khabir-prod.** All external
   actions below still require owner approval.

### Incident disclosure

During the initial baseline, before the isolation guard was added, the
integration specs read `apps/api/.env` and connected to **khabir-dev**; the
service-request concurrency probe ran there. The suites use deterministic
probe markers and cleanup, but the owner must verify no residual rows remain.
After `eda245f`, tests can only use loopback/CI hosts, and any Supabase URL
fails loudly.
